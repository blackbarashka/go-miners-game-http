# Coal Mine Management Simulation

Учебный бэкенд-проект на Go. Симулятор управления угольной шахтой с упором на конкуррентное программирование (горутины, каналы, контексты), интерфейсы и построение REST API.

---

## Архитектура и особенности

* **Фоновый доход:** Пассивное поступление угля (1 ед. в секунду) реализовано через отдельную фоновую горутину с использованием `time.Ticker`.
* **Конкурентные вовлечения:** Каждый нанятый шахтёр работает в собственной горутине, с заданной периодичностью добывает ресурс и отправляет его в общий канал предприятия.
* **Потокобезопасность:** Доступ к общему состоянию (баланс, мапы рабочих и оборудования) защищен с помощью `sync.Mutex`.
* **Управление жизненным циклом:** Использование `context.Context` позволяет в любой момент корректно остановить работу всех фоновых процессов и шахтёров.
* **REST API:** Транспортный слой на стандартном `net/http` для взаимодействия с игрой через HTTP-запросы.

## Игровая механика

### Шахтёры
В игре доступно три класса работников:
* **Маленький:** стоимость найма — 5 угля, запас энергии — 30 добыч, приносит 1 уголь за 3 секунды.
* **Нормальный:** стоимость найма — 50 угля, запас энергии — 45 добыч, приносит 3 угля за 2 секунды.
* **Сильный:** стоимость найма — 450 угля, запас энергии — 60 добыч, приносит 10 угля за 1 секунду (с каждой добычей объем получаемого угля увеличивается на 3).

### Цель игры
Необходимо накопить ресурсы и приобрести три типа оборудования:
* Кирки (3,000 угля)
* Вентиляция (15,000 угля)
* Вагонетки (50,000 угля)

## Эндпоинты REST API

**Шахтёры:**
* `GET /payment?class=<class>` — узнать стоимость найма шахтёра нужного класса.
* `POST /miners` — нанять шахтёра (тело запроса: `{"class": "small" | "normal" | "strong"}`).
* `GET /workers` — получить общую статистику нанятых шахтёров.
* `GET /workers?class=<class>` — фильтрация рабочих по конкретному классу.

**Оборудование:**
* `GET /equipment/cost` — актуальные цены на все виды оборудования.
* `POST /equipment/buy?equipment=<name>` — покупка оборудования (`pickaxes`, `ventilation`, `carts`).
* `GET /equipment` — список всего оборудования.
* `GET /equipment?purchased=true` / `false` — фильтрация по статусу приобретения.

## Запуск

1. Склонировать репозиторий и перейти в директорию проекта.
2. Запустить приложение:
   ```bash
   go run main.go
   ```
Сервер поднимется на порту 8080.
